## 中文内容
## 项目状态
🎉 v0.0.1 初始版本已发布（2026-10-09），开放下载试玩。
当前为单人 / 局域网玩法的早期可玩版本，核心经营循环（顾客点单、菜品交付、声望与星级结算、休店日管理）已可运行。后续版本将持续补充店铺升级解锁等成长系统。

已知限制：
- 仍处于快速迭代期，存档兼容性与数值平衡可能随版本调整；
- 暂不支持多人服务器部署；
- 游玩中遇到问题，欢迎通过 Issue 反馈，并尽量附上触发场景与截图。

## 项目概况
- 适配版本：Minecraft 1.20.1 Forge
- 载体形式：餐厅定制地图 + 专属整合包 + KubeJS脚本联动
- 游玩范围：仅支持单人游玩、对局域网开放，
- 内容设定：纯餐厅经营模拟玩法，无战斗、魔法相关内容

## 分支说明
- `main`：默认主分支，存放测试完毕的稳定正式资源
- `dev`：日常编写、调试、迭代更新的开发分支

## 开发须知
本项目由学生作者单人独立开发；本人对JS尚不熟悉，时间精力有限，开发周期会相对漫长，敬请耐心期待。
