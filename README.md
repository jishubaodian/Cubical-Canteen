## 项目概况
- 适配版本：Minecraft 1.20.1 Forge
- 载体形式：餐厅定制地图 + 专属整合包 + KubeJS脚本联动
- 游玩范围：仅支持单人游玩、对局域网开放，**不支持多人服务器部署**
- 内容设定：纯餐厅经营模拟玩法，无战斗、魔法相关内容

## 分支说明
- `main`：默认主分支，存放测试完毕的稳定正式资源
- `dev`：日常编写、调试、迭代更新的开发分支
